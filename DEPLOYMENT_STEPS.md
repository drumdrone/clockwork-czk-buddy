# 🚀 Nasazení na GitHub Pages

Váš projekt je **připravený k nasazení**! Stačí 3 jednoduché kroky.

## ✅ Hotovo automaticky:
- ✓ Vite konfigurace pro GitHub Pages
- ✓ GitHub Actions workflow
- ✓ Deploy script v package.json
- ✓ Změny pushnuty na GitHub

---

## 📋 Co musíte udělat (2 minuty):

### Krok 1: Mergnut Pull Request
**Klikněte zde a potvrďte merge:**

👉 https://github.com/drumdrone/clockwork-czk-buddy/compare/main...claude/clockwork-czk-buddy-zP1Wv

Nebo:
1. Jděte na https://github.com/drumdrone/clockwork-czk-buddy
2. Klikněte na "Compare & pull request" (žlutý banner nahoře)
3. Klikněte "Create pull request"
4. Klikněte "Merge pull request"
5. Klikněte "Confirm merge"

---

### Krok 2: Zapnout GitHub Pages (KRITICKÉ!)
**Přímý odkaz na nastavení:**

👉 https://github.com/drumdrone/clockwork-czk-buddy/settings/pages

Nastavte:
- **Source**: `GitHub Actions` (NE "Deploy from branch"!)

💡 Musíte mít admin přístup k repository.

---

### Krok 3: Počkat 2-3 minuty
GitHub Actions automaticky sestaví aplikaci.

**Sledujte build zde:**
👉 https://github.com/drumdrone/clockwork-czk-buddy/actions

---

## 🎉 Výsledek:
Po dokončení bude aplikace dostupná na:

```
https://drumdrone.github.io/clockwork-czk-buddy/
```

Pak se k ní dostanete z jakéhokoliv zařízení!

---

## 🔍 Řešení problémů:

**Build selhává?**
- Zkontrolujte Actions tab na GitHubu
- Ujistěte se, že jste vybrali "GitHub Actions" jako source v Pages settings

**404 chyba?**
- Počkejte 5 minut, první deploy může trvat déle
- Zkontrolujte, že URL začína s `https://drumdrone.github.io/clockwork-czk-buddy/`

**Need help?**
- Zkontrolujte https://github.com/drumdrone/clockwork-czk-buddy/actions
- Případně mi dejte vědět!
